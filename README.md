# Birthday Card

An interactive birthday card that cycles through a sequence of images when clicking a button, revealing a final message at the end.

## Features

- Click-through image sequence with smooth fade transitions
- Customizable colors, fonts, and content
- Responsive design for mobile and desktop

## Project Structure

```ini
bday-card/
├── index.html          # Main HTML structure
├── index.js            # Image cycling logic
├── style.css           # Styling with CSS variables
├── assets/
│   ├── image-content/  # Sequential images (image-1.png to image-6.png)
│   ├── main-bg.png     # Page background
│   ├── favicon.png     # Browser tab icon
│   ├── close-icon.png  # Decorative window control
│   └── shrink-icon.png # Decorative window control
└── README.md
```

## Tech Stack

- Vanilla HTML, CSS, JavaScript
- [Pixelify Sans](https://fonts.google.com/specimen/Pixelify+Sans) font via Google Fonts
